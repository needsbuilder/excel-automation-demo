# 월별 업무시간 집계

**가상 데이터로 만든 작업 예시입니다. 실제 고객 자료나 납품 실적이 아닙니다.**

날짜와 작업시간이 있는 기록을 연도·월별로 묶습니다. 중복 기록ID는 두 행을 모두 확인 대상으로 남기며 존재하지 않는 날짜와 잘못된 시간도 집계에서 제외합니다. 누락을 숨기지 않도록 정상·확인 건수를 함께 표시합니다.

## 가상 예시 결과

입력 9건 중 정상 5건, 확인 4건입니다. 정상 시간 합계는 **300분(5시간)**이며 다음처럼 나뉩니다.

| 달 | 정상 기록 시간 / 분 |
| --- | ---: |
| 2026-09 | 60 |
| 2026-10 | 120 |
| 2027-01 | 120 |

기록 6·7은 중복 ID, 기록 8은 존재하지 않는 9월 31일, 기록 9는 음수 시간입니다. 결과에 입력 순서 기준 원본 기록 번호가 남습니다. `0001` 같은 ID는 문자열로 보존합니다.

## 브라우저에서 확인하기

[월별 업무시간 실행 예시](https://needsbuilder.github.io/excel-automation-demo/monthly-worklog-example.html)에서 설치 없이 가상 9건을 계산할 수 있습니다. 첫 기록의 날짜와 시간만 바꿀 수 있으며 나머지 8건은 고정됩니다. 최신 결과는 JSON으로 받습니다. 입력을 변경하면 이전 결과와 다운로드를 지우고 다시 실행하도록 안내합니다. 고객 파일 업로드·서버 전송은 없습니다.

브라우저 계산은 Python과 10개 입력 사례 및 입력 한도를 대조했습니다. 실제 Excel·VBA·Apps Script 실행 검증을 뜻하지 않습니다.

## 실행과 검증

Python 3 표준 라이브러리로 실행합니다. 추가 도구 결제나 설치 패키지는 없습니다. ZIP을 풀고 해당 폴더에서 실행하세요.

```sh
python3 monthly_report.py input.json my-result.json
python3 -m unittest -v test_acceptance.py
```

입력은 UTF-8 JSON 배열입니다. 각 기록은 `record_id`(문자열), `date`(`YYYY-MM-DD`), `minutes`(0~1440의 정수) 세 항목입니다. 파일 최대 1MB, 기록 최대 10,000건입니다. 시간은 분 단위로 정확히 더하며 입력의 날짜로 달을 구분합니다. 날짜를 바꾸면 월별 집계도 바뀝니다.

원본은 읽기만 하며 기존 결과도 덮어쓰지 않습니다. 새 결과 이름을 사용하세요. 중복 ID는 양끝 공백을 제거한 뒤 비교합니다. 다른 필드나 형식은 임의로 추측하지 않고 확인 대상으로 남깁니다.

5개 수락 테스트로 고정 기대 합계, 첫 기록을 10월·90분으로 바꾼 330분, 연도 경계, 윤년·날짜 오류, 0분·상한·음수·소수·문자·빈값, 중복·누락 필드, 원본 보존, 기존 결과 보존, 잘못된 입력에서 결과 미생성을 확인합니다.

## 실제 업무에서 먼저 정할 것

급여·수당 계산, 근무 평가, 휴게시간 차감, 야간 근무 분할, 시간대 변환, 여러 직원 기록의 같은 날 총시간 제한은 포함하지 않습니다. 한 기록의 시간 범위만 검사합니다. 직원별·프로젝트별 집계나 취소 기록 처리는 별도 규칙이 필요합니다.

실제 Microsoft Excel·VBA·Apps Script 및 외부 업무 시스템 연동은 미검증입니다. JSON 입력을 Python으로 계산한 예시이며 엑셀 파일을 수정하는 도구가 아닙니다. 현재 사용하는 파일의 개인정보를 가린 샘플, 원하는 집계표, 중복·취소 처리 기준과 실행 환경을 [크몽 니즈랩 메시지](https://kmong.com/gig/824498)로 알려주시면 구매 전 범위와 검증 환경을 확인합니다. 고객 파일은 크몽 메시지 첨부로 받으며 공개 댓글에는 올리지 마세요.
