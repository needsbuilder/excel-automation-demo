# 두 상품목록의 변경 비교

**가상 데이터로 만든 작업 예시입니다. 실제 고객 자료나 납품 실적이 아닙니다.** 이전·현재 CSV를 정확한 상품코드로 비교하여 신규, 현재 목록에 없는 상품, 변경, 동일, 확인 필요를 구분합니다. 목록에서 빠졌다는 사실만 표시하며 상품 삭제나 판매 종료를 판단하거나 실행하지 않습니다.

Python 3 표준 라이브러리로 실행합니다. Excel 설치와 추가 라이브러리는 필요 없습니다.

```sh
python3 compare_catalog.py before.csv after.csv my-result
python3 -m unittest test_acceptance.py
```

입력은 UTF-8 CSV이고 열·순서는 `상품코드,상품명,단가`입니다. 상품코드·상품명의 양끝 공백은 제거하지만 앞자리 0은 유지합니다. 단가는 0 이상의 정수 원화입니다. 중복 코드, 빈 코드, 잘못된 금액은 임의 선택·합산하지 않고 확인으로 남깁니다. 오류가 있는 코드의 다른 쪽 행도 함께 표시하여 신규나 누락으로 오판하지 않습니다.

| 고정 기대값 | 결과 |
| --- | --- |
| 입력 | 이전 8행, 현재 6행 |
| 신규 | 0007, 1건 |
| 현재 목록에 없음 | 0003, 1건 |
| 변경 | 0001 단가 변경, 0004 상품명·단가 변경, 2건 |
| 동일 | 0002, 1건 |
| 확인 필요 | 0005 중복, 0006 잘못된 단가, 코드 없는 행, 3건 |

결과 CSV에는 이전·현재 값과 원본 CSV 행 번호가 있습니다. `result.json`은 코드 문자열을 보존합니다. Excel이 CSV를 열 때 상품코드를 숫자로 자동 변환할 수 있으므로 데이터 가져오기에서 해당 열을 **텍스트**로 지정하세요. CSV의 수식 시작 문자는 작은따옴표로 보호합니다. 원본은 읽기만 하고 기존 결과 폴더에는 덮어쓰지 않습니다.

단가를 1000원으로 되돌리면 변경 1건·동일 2건입니다. 입력 변경, 중복·오류 분리, 앞자리 0, CSV 수식 문자 보호, 원본 해시 및 기존 결과 보존을 수락 기준으로 검증합니다. 실제 Excel·VBA·Apps Script와 외부 상품 시스템 실행은 미검증입니다. 환율·부분 일치·코드가 바뀐 상품의 추정 연결은 지원하지 않습니다.
