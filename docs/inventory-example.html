부족한 품목을 확인.

가용 수량 = 현재 재고 − 예약 수량.
중복 품목·예약 초과·수량 오류는 따로 확인합니다.

브라우저 안에서 가상 데이터만 계산합니다. 파일 업로드와 서버 전송은 없습니다.

01 / INPUT기존 가상 재고 7행

목표보다 부족한 가용 수량

부족 수량 = 목표 가용 수량 − 가용 수량. 음수일 때는 0개로 표시합니다.

재고를 바꿔 확인하기

S002 재고를 7개에서 14개로 바꾸면 부족 합계가 15개에서 8개로 줄어듭니다.

입력 재고 · 원본 배열의 행 번호
품목재고예약목표행

수량은 0 이상의 정수입니다. 품목ID가 중복되면 모든 해당 행을 확인 대상으로 남기며 임의로 합산하지 않습니다.

02 / RESULT실행 전

부족 수량과 확인할 내역

—정상 행
—확인할 행
—부족 합계 / 개

샘플 기대값: 정상 3행, 확인 4행, 부족 2품목 / 15개.

품목별 점검 · 확인 사유
품목가용부족판정 / 사유원본 행
