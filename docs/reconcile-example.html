가상 데이터로 만든 작업 예시

주문과 입금,
같은 ID로 대조.

총합을 보기 전에 각 주문을 확인합니다.
금액 차이·미입금·중복 ID·주문 없는 입금을 구분합니다.

가상 원본·결과 CSV 받기 ↓

브라우저 안에서만 계산합니다. 파일 업로드나 서버 전송은 없습니다.

01 / INPUT가상 CSV 2개

같은 주문ID로 연결

주문.csv: D100 30,000원 / D101 20,000원 / D102 40,000원 / D103 50,000원

입금.csv: D100 30,000원 / D101 19,000원 / D103 25,000원 두 건 / D999 10,000원

입금액을 바꿔 확인하기

D101 주문액은 20,000원입니다. 아래 입금액을 20,000원으로 바꾼 뒤 다시 실행하면 ‘일치’가 됩니다.

주문ID는 각 파일에서 1회만 등장한다는 규칙입니다. 분할입금·수수료·환불·다른 통화·입금자명 유사 매칭은 이 예시에서 처리하지 않습니다. 중복은 확인 대상으로 남깁니다.

02 / RESULT실행 전

확인할 항목을 따로

—일치 ID
—확인할 ID
—입금 합계 / 원

가상 샘플: 일치 1건, 확인할 ID 4건, 입금 합계 109,000원.

주문ID별 대조 · 원본 행 번호는 헤더 다음 2행부터
주문ID주문액입금액판정원본 행
실행하면 결과가 표시됩니다.

실제 고객 자료나 납품 실적이 아닌 가상 기술 작업 예시입니다. 정수 원화와 정확한 주문ID 일치를 사용합니다. 브라우저와 Node.js에서 계산·입력 변경·CSV 결과를 검증하며, 실제 Excel·VBA·Apps Script 실행 예시는 아닙니다. 실제 고객 파일에 적용할 때는 열 구조와 대조 규칙을 별도로 합의해야 합니다.
